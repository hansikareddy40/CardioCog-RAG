PROJECT TITLE
-------------
CardioCog-RAG: Explainable Early Prediction of Cognitive Decline Using Cardiovascular Risk Factors, Longitudinal Cognitive Trajectories, APOE/Genetic Information, and Brain PET Biomarkers.

PROJECT GOAL
------------
The goal is to develop an explainable multimodal AI framework using NACC data to investigate whether cardiovascular/medical risk factors, longitudinal cognitive trajectories, demographic information, APOE/genetic information, and available amyloid/tau PET biomarkers can be combined to predict future cognitive decline or cognitive-risk progression.

IMPORTANT:
This is NOT simply an Alzheimer's image-classification project.
The core idea is MULTIMODAL + LONGITUDINAL + EXPLAINABLE AI.

We want to combine:
1. Cardiovascular/medical information
2. Cognitive information over multiple visits
3. Demographics
4. APOE/genetic information
5. Amyloid PET / Tau PET information
6. Explainability
7. Evidence-grounded RAG reporting

CORE FEATURE GROUPS
-------------------

A. DEMOGRAPHIC FEATURES
-----------------------
Use relevant NACC demographic/context variables that are actually available.

Potential categories include:
- age
- sex
- education
- race/ethnicity
- other justified demographic variables

Why:
Demographics provide participant context and are important confounders/covariates when interpreting cognitive outcomes.

IMPORTANT:
Exact feature names must come from the NACC RDD.


B. CARDIOVASCULAR / MEDICAL FEATURES
------------------------------------
The project wants to capture cardiovascular and vascular/metabolic burden.

Potential NACC variables/categories to investigate include:
- blood pressure
- hypertension-related information
- diabetes
- cardiovascular disease
- cerebrovascular disease
- vascular risk factors
- weight
- height
- BMI/anthropometrics where available
- relevant medical history
- smoking or other relevant risk factors if available and justified

WHY:
Cardiovascular and cerebrovascular health can be associated with brain health and cognitive decline.

IMPORTANT:
Do not call every medical variable "cardiovascular".
Only variables with a defensible cardiovascular/vascular/metabolic relationship should enter the cardiovascular feature group.


C. COGNITIVE FEATURES
---------------------
Cognitive information is a central component.

We want to investigate NACC cognitive/clinical measures such as:
- CDR
- neuropsychological memory measures
- executive-function measures
- language measures
- attention/processing measures
- orientation or related cognitive measures
- relevant diagnostic/staging variables

The exact cognitive variables must be mapped from the RDD.

WHY:
These measurements provide the actual observed cognitive state of the participant.

More importantly, NACC is longitudinal.

Therefore we want to preserve:
Visit 1 → Visit 2 → Visit 3 → Visit 4 → ...

rather than collapsing everything into a single row.

This allows us to model cognitive trajectory.


D. LONGITUDINAL INFORMATION
---------------------------
Longitudinal means repeated observations of the SAME participant over time.

Example:

NACCID 1234

Visit 1:
Cognitive score = X

Visit 2:
Cognitive score = Y

Visit 3:
Cognitive score = Z

The model can learn:
- baseline status
- direction of change
- rate of change
- temporal patterns
- which visits are informative

Potential derived features:
- change from baseline
- change from previous visit
- annualized cognitive change where justified
- time between visits

IMPORTANT:
The target and prediction horizon must be defined BEFORE modelling.

Avoid data leakage.


E. GENETIC INFORMATION
----------------------
The primary planned genetic feature is APOE.

APOE is relevant because APOE genotype is associated with Alzheimer's disease risk and can provide genetic risk/context.

IMPORTANT:
APOE is NOT the same thing as whole-genome sequencing.

Do not claim that the project uses complete genomic sequencing unless such data are separately verified and included.


F. PET DATA
-----------
PET is important because it provides biological/pathological information rather than simply structural anatomy.

Amyloid PET:
Provides information about amyloid-related pathology.

Tau PET:
Provides information about tau-related pathology.

Potential quantitative PET features to investigate:
- SUVR
- centiloid values where available
- tracer
- scan date
- PET modality/type
- protocol
- QC
- reference-region information where available
- regional measurements if provided

EXACT PET VARIABLES MUST BE VERIFIED FROM THE NACC PET RDD/files.


MRI VS PET
----------
MRI:
- primarily structural/anatomical
- shows brain structure
- can provide volume, cortical thickness, atrophy etc.

PET:
- tracer-based
- provides information about biological/pathological processes
- amyloid PET relates to amyloid pathology
- tau PET relates to tau pathology

The current project is primarily focused on PET, not MRI.

Do not add MRI into the core pipeline unless the project is deliberately expanded later.

IMPORTANT:
Do NOT assume:
- voxel size
- image dimensions
- preprocessing
- normalization method
- scanner/protocol
- image format

These must be determined from the actual files first.

For structured/tabular data:

1. Logistic Regression
2. Random Forest
3. XGBoost
4. CatBoost

These should be used as baselines/comparisons.

CatBoost is a strong candidate for mixed structured clinical data.


DEEP LEARNING
-------------

1. LSTM
-------
Used for longitudinal sequences.

Input:
Repeated cognitive/clinical observations over visits.

Output:
Temporal representation.


2. Transformer
--------------
Optional comparison for longitudinal modelling.

Do not automatically use it if sample size is too small.


3. 3D CNN / 3D ResNet
---------------------
Used only if actual PET images are available in sufficient quantity.

Input:
3D PET volume.

Output:
PET feature embedding.

DATA LEAKAGE
------------

THIS IS CRITICAL.

The same NACC participant can have multiple visits.

Therefore:

WRONG:
Randomly split individual rows.

CORRECT:
Split by NACCID.

All visits from one participant must remain in the same train/validation/test partition.

Also:
- fit imputer only on training data
- fit scaler only on training data
- fit encoder only on training data
- do not use future cognitive measurements as predictors of the future target
- define baseline and prediction horizon before modelling
- be careful with PET timing
- do not use post-baseline information if the research question is early prediction from baseline.


EXPLAINABILITY
--------------

SHAP:
Used primarily for structured/tabular features.

It answers:
"Which features contributed to this prediction?"

Example:
- APOE
- blood pressure
- diabetes
- cognitive score
- age
- PET measurement

SHAP does NOT prove causality.


GRAD-CAM:
Only for CNN-based PET image modelling.

It can highlight image regions that contributed to the model output.


TEMPORAL ATTENTION:
Can show which visits/time points receive higher model attention.


RAG
---

RAG = Retrieval-Augmented Generation.

It is NOT the prediction model.

The prediction model produces:
- risk
- progression prediction
- feature importance
- PET/image explanation

Then RAG retrieves relevant trusted scientific/clinical evidence.

Pipeline:

Prediction
   ↓
SHAP / attention / Grad-CAM
   ↓
retrieve supporting literature
   ↓
LLM
   ↓
evidence-grounded explanation


LLM ROLE
--------
The LLM should NOT independently diagnose the participant.

It should:
- summarize model outputs
- summarize important contributing features
- explain relevant evidence
- generate a readable report
- clearly distinguish prediction from medical fact
- cite retrieved evidence


IMPORTANT SCIENTIFIC POSITION
-----------------------------
This is a research prediction/decision-support framework.

It should NOT be described as a clinically validated diagnostic system.

The model predicts statistical risk/progression based on the available NACC data.

THE SIMPLEST DESCRIPTION OF THE PROJECT
----------------------------------------

We are using NACC longitudinal clinical data to combine cardiovascular/medical risk factors, cognitive trajectories, demographics, APOE, and Alzheimer's-related PET biomarkers.

The model will learn from these complementary information sources to predict future cognitive risk/progression.

Then SHAP, temporal attention and potentially Grad-CAM explain the prediction.

Finally, RAG retrieves trusted scientific evidence and an LLM converts the model outputs into an understandable evidence-grounded explanation.

The first task is NOT modelling.

The first task is:
AUDIT THE ACTUAL NACC FILES → MAP EXACT VARIABLES → BUILD THE COHORT → VERIFY PET → DEFINE TARGET → THEN MODEL.
