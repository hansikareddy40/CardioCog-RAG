\chapter{Implementation and Reproducibility Notes}
\label{app:repro}

\section{Software}
Python 3.11 with the package versions listed in \texttt{requirements.txt}: NumPy 1.26, pandas 2.3, scikit-learn 1.6, XGBoost 3.0, PyTorch 2.8, SHAP 0.48, lifelines 0.30, SimpleITK 2.5, pydicom 3.0, sentence-transformers 6.1, FastAPI 0.116 and React 18 for the interface.

\section{Pipeline}
With the NACC files placed under \texttt{data/raw/}, every result is regenerated by running the scripts below in order.
{\raggedright
\begin{enumerate}[noitemsep]
\item Cohort and features: \texttt{audit\_data.py}, \texttt{build\_dataset.py}.
\item Dementia models: \texttt{train\_tabular.py}, \texttt{train\_by\_baseline\_group.py}, \texttt{train\_longitudinal.py}, \texttt{explain.py}.
\item PET and validation: \texttt{train\_pet.py}, \texttt{validate.py}, \texttt{train\_final.py}.
\item Decline outcomes and fusion network: \texttt{train\_decline.py}, \texttt{train\_fusion\_network.py}.
\item Sensitivity analysis: \texttt{sensitivity\_confirmed.py}.
\item PET image pipeline: \texttt{pet\_convert.py}, \texttt{pet\_register.py}, \texttt{pet\_suvr.py}, \texttt{train\_pet\_image.py}.
\item Evidence assistant: \texttt{rag\_build.py}, \texttt{rag\_eval.py} (retrieval and answering in \texttt{rag.py}).
\item Checks: \texttt{verify\_results.py}, \texttt{check\_clinical\_behaviour.py}.
\item Figures: the twelve notebooks in \texttt{notebooks/} redraw the project figures from the saved results, and \texttt{thesis/make\_figures.py} and \texttt{thesis/make\_result\_figures.py} draw the remaining thesis figures.
\end{enumerate}\par}

\section{Seeds}
Data split: 2026. Model training: 0, 1 and 2, averaged. Image cross-validation: 0.

\section{Data Access}
Participant-level data and trained models cannot be distributed under the NACC data use agreement. All reported results are aggregates and are stored in the \texttt{reports} directory of the project repository.
